# 単語 (tango)

개인용 오프라인 일본어 단어장. iPhone Safari에서 열고 **공유 → 홈 화면에 추가**를 누르면 앱처럼 쓸 수 있고, 한 번 열어둔 뒤로는 인터넷 없이도 동작한다.

- かな→한, 漢字→한, 한→일, 문장 카드를 방향마다 따로 복습 (FSRS 간격 반복)
- 후리가나(あ)와 한글 발음(가)을 따로 켜고 끄기
- 한글 발음은 읽기에서 자동 생성, 장음은 대시 (せんしゅう → 센슈-, ネイビー → 네이비-)
- 타이핑 세션 (한→일, 히라가나·가타카나·한자 모두 정답 처리)
- 하루 새 단어 수 설정, 그날만 +10/+20/+50
- 오늘 틀린 것 다시보기 (복습 일정에는 영향 없음)
- 덱 내보내기/가져오기 (`tango-deck-v1` JSON), 전체 백업/복원

데이터는 기기의 localStorage 에만 있다. 서버도 계정도 없다.

## 단어 넣기

1. 단어장 → 가져오기 → **프롬프트 복사**
2. ChatGPT에 프롬프트 + 유튜브 스크립트를 붙여넣기
3. 답변을 통째로 복사해서 앱에 붙여넣기 (코드 블록 여러 개여도 됨)

덱 파일 형식:

```json
{
  "format": "tango-deck-v1",
  "deck": "일본어 회화 1회차",
  "cards": [
    { "word": "先週", "reading": "せんしゅう", "meaning": "지난주", "pos": "명사",
      "sentence": "今日[きょう]は先週[せんしゅう]…", "sentence_ko": "오늘은 지난주…", "time": "00:00" }
  ]
}
```

`sentence` 의 후리가나는 한자 덩어리 바로 뒤 `[읽기]`.

## 개발

빌드 없음. 정적 파일 그대로.

```bash
python3 -m http.server 8765   # http://127.0.0.1:8765
```

배포는 GitHub Pages (main 브랜치 루트). 앱 파일을 고치면 `sw.js` 의 `CACHE` 버전을 올린다. 그래야 폰에서 새 버전을 받는다 (다음 실행 때 적용).

`decks/` 는 개인 학습 자료라 저장소에 올리지 않는다 (.gitignore).

`vendor/ts-fsrs.umd.js` — [ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs) 5.4.1, MIT.
